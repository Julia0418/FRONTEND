Capítulo 6
A Guarda da Tela

    

      

        
O wrap ajudou, mas o card ainda não cabia direito. Foi aí que chegou a Guarda Media, vigia dos 600px.

        

          
Alto lá! Até 600px de largura, valem as regras do celular!

          

            
            
/* até 600px de largura */
@media (max-width: 600px) {
  /* regras do celular */
}

Mesmo HTML, outro layout. Só o CSS muda!

          
        

      

    

    

      

        
O livro de regras da Guarda, linha por linha:

        

          

            
@media (max-width: 600px) {
  form {
    flex-direction: column;
    align-items: stretch;
  }

  article {
    flex-direction: column;
    align-items: flex-start;
    gap: 12px;
  }

  article div.acoes {
    width: 100%;
    justify-content: flex-end;
  }
}

            

              
form: os campos viram coluna e esticam na largura toda.

              
article: o texto fica em cima e os botões embaixo.

              
.acoes: ocupam a linha inteira, alinhados à direita.

Final
Missão da turma


    

      
Folha de cola da Dona Flex

      

        
display: flex
Vai no PAI. Transforma os filhos em itens flex.

        
flex-direction
Define o eixo principal: row (→) ou column (↓).

        
justify-content
Distribui os itens ao longo do eixo principal.

        
align-items
Alinha os itens no eixo cruzado.

        
gap
Espaço entre os itens, sem precisar de margin.

        
flex-wrap
wrap deixa quem não cabe descer para a próxima linha.

        
flex: 1 e min-width
Dividem o espaço livre, mas ninguém fica mais estreito que o mínimo.

        
@media
A Guarda da Tela: max-width: 600px troca as regras no celular.

      

    


    

      
Desafios
Tente responder antes de abrir

      

        
1. Quero os 3 botões no centro da barra. Qual propriedade e valor?
          
No pai com display: flex, use justify-content: center.

        
2. Meus itens estão em coluna, mas eu queria centralizá-los na horizontal. E agora?
          
Com flex-direction: column, o eixo principal é vertical. A horizontal virou o eixo cruzado, então use align-items: center.

        
3. Como faço o menu virar coluna só em telas de até 768px?
          
@media (max-width: 768px) {
  nav { flex-direction: column; }
}

        
4. Três cards lado a lado. O do meio deve ter o dobro da largura dos outros.
          
Use flex: 1 nos dois cards das pontas e flex: 2 no do meio. O espaço livre é dividido em 4 partes: 1 + 2 + 1.
