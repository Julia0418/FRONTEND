Parte 1

Os nomes da árvore

Dom reuniu a turma debaixo da própria sombra: "Hoje vocês vão aprender a falar o idioma da árvore."

Tudo no DOM é um nó (em inglês, node). Cada pedacinho da página vira um nó: o documento, os elementos, os textos…
A página é uma árvore de nós!

Os três tipos de nó que você mais vai encontrar:

Documentodocument: a raiz de toda a árvore e a porta de entrada do JavaScript.
ElementoCada tag do HTML: <ul>, <li>, <button>.
TextoO que está escrito dentro de um elemento. Cada texto é um nó.

A árvore tem parentesco, como uma família. Olhe este pedaço de página:

<body>
  <ul id="lista">
    <li>Estudar</li>
    <li>Treinar</li>
  </ul>
</body>
  • body ← avô dos li
    • ul#lista ← PAI dos dois li
      • li ← FILHO do ul
      • li ← IRMÃO do outro li

Resumindo a família:

Quem está dentro é filho. Quem tem o mesmo pai é irmão. Quem está acima de todos é a raiz.

    HTML, DOM e JavaScript

    A relação mais importante da aula: planta e casa.

    O arquivo HTML é a planta. O DOM é a casa construída. O JavaScript reforma a casa, mas não mexe na planta!
    index.htmla planta (texto no arquivo) → DOMa casa (na memória)

    O caminho de um arquivo HTML até a tela, e onde o JavaScript entra.

    1 · Arquivoindex.html é só texto → 2 · Navegador lêtransforma o texto em objetos → 3 · DOMárvore de nós na memória → 4 · Telao que a pessoa vê
    JavaScriptlê e altera o DOM (passo 3). A tela se atualiza sozinha.
    O JS fala com o DOM, nunca com o arquivo. É por isso que document.getElementById começa com document.

    Sr. Reload aparece para provar a regra.

    Recarreguei! O DOM voltou a ser igual ao arquivo!
    Tudo que o JS tinha criado evaporou…

    Dica de detetive: dois jeitos de espiar a página, dois resultados diferentes.

    Exibir código-fonte (Ctrl+U) mostra o arquivo original, sem as mudanças do JS.
    Inspecionar (F12, aba Elements) mostra o DOM de agora, com tudo o que o JS fez.

        Parte 4

        Oficina de código

        Agora é no editor! Cada desafio tem o HTML inicial. Tente escrever o JavaScript antes de abrir a solução.

        Mão na massa!
        Regra da oficina: 1) selecione, 2) escute, 3) altere. Sempre nessa ordem.

        Desafio 1 · Saudação

        Ao clicar no botão, o título deve mudar para Olá, DOM!.

        <h1 id="titulo">Olá!</h1>
<button id="btn-saudar">Saudar</button>
<script src="script.js"></script>
        Dica

        O evento do botão chama-se click. Para mudar o texto, use textContent.

        Solução 
        const titulo = document.getElementById('titulo');
const botao = document.getElementById('btn-saudar');

botao.addEventListener('click', function () {
  titulo.textContent = 'Olá, DOM!';
});

        Desafio 2 · Contador de cliques

        Cada clique no botão soma 1 ao número que aparece na tela.

        <p>Cliques: <span id="numero">0</span></p>
<button id="btn-mais">+1</button>
<script src="script.js"></script>
        Dica

        Guarde o total em uma variável let fora da função. Dentro dela, some 1 e escreva o novo valor no span.

        Solução 
        const numero = document.getElementById('numero');
const botao = document.getElementById('btn-mais');
let total = 0;

botao.addEventListener('click', function () {
  total = total + 1;
  numero.textContent = total;
});

        Desafio 3 · Catálogo do CineDev

        Ao enviar o formulário, crie um card com o título e o gênero dentro de #catalogo, sem recarregar a página. Não aceite título vazio. Limpe o formulário no final.

        <form id="form-filme">
  <input type="text" id="titulo" placeholder="Título do filme">
  <select id="genero">
    <option>Ação</option><option>Comédia</option><option>Drama</option>
  </select>
  <button type="submit">Adicionar</button>
</form>
<section id="catalogo"></section>
        Dica

        É a mesma receita do DevTask: selecionar, escutar o submit, preventDefault(), ler .value, criar, inserir e limpar.

        Solução 
        const form = document.getElementById('form-filme');
const inputTitulo = document.getElementById('titulo');
const selectGenero = document.getElementById('genero');
const catalogo = document.getElementById('catalogo');

form.addEventListener('submit', function (event) {
  event.preventDefault();
  const titulo = inputTitulo.value.trim();
  if (titulo === '') {
    alert('Digite o título do filme!');
    return;
  }
  const card = document.createElement('article');
  card.innerHTML = `<h3>${titulo}</h3><p>Gênero: ${selectGenero.value}</p>`;
  catalogo.appendChild(card);
  form.reset();
  inputTitulo.focus();
});

        Desafio 4 · Limpar a lista

        Ao clicar em Limpar, a lista deve ficar vazia e o parágrafo deve avisar Nenhuma tarefa por aqui!.

        <ul id="lista">
  <li>Estudar DOM</li><li>Treinar JS</li>
</ul>
<p id="aviso"></p>
<button id="btn-limpar">Limpar</button>
        Dica

        Atribuir uma string vazia ao innerHTML de um elemento esvazia tudo o que tem dentro dele.

        Solução 
        const lista = document.getElementById('lista');
const aviso = document.getElementById('aviso');

document.getElementById('btn-limpar').addEventListener('click', function () {
  lista.innerHTML = '';
  aviso.textContent = 'Nenhuma tarefa por aqui!';
});

        Ações entre JavaScript e HTML

        Para fechar com chave de ouro, a Capitã Script mostra oito jeitos de o JavaScript mexer no HTML.

        KAPOW!
        Aperte os botões e leia o código!
        O código de cada cartão é exatamente o que roda ali. Repare também no quadro escuro: ele mostra o HTML mudando no DOM.

        Ação 1 · Trocar o texto

        textContent lê e muda o texto de um elemento.

        Olá, mundo!

        const titulo = document.getElementById('a1-t');
titulo.textContent = 'Texto trocado pelo JS!';

        Ação 2 · Mudar o estilo

        style muda o CSS de um elemento na hora.

        Caixa estilizável
        const caixa = document.getElementById('a2-box');
caixa.style.backgroundColor = '#ff6b81';
caixa.style.fontSize = '24px';
caixa.style.borderRadius = '999px';
caixa.removeAttribute('style');   // limpa tudo

        Ação 3 · Ligar e desligar classes

        classList adiciona, remove e alterna classes CSS: o jeito mais limpo de mudar o visual.

        Cartão com classes
        const cartao = document.getElementById('a3-card');
cartao.classList.toggle('destaque');
cartao.classList.add('grande');
cartao.classList.remove('grande');
cartao.classList.contains('destaque'); // true ou false

        Ação 4 · Mudar atributos

        Atributos como placeholder, disabled e type também são do DOM.

        const campo = document.getElementById('a4-in');
campo.setAttribute('placeholder', 'Digite aqui');
campo.disabled = true;
campo.type = 'text';   // mostra a senha

        Ação 5 · Ocultar e remover

        hidden esconde, mas o elemento continua no DOM. remove() tira o elemento da árvore.

        Mensagem secreta da Capitã

        const msg = document.getElementById('a5-msg');
msg.hidden = true;               // some da tela
msg.hidden = false;              // volta
msg.remove();                    // sai do DOM
palco.appendChild(msg);          // volta para o DOM

        Ação 6 · Reagir ao que a pessoa digita

        O evento input dispara a cada letra digitada.

        Digite seu nome…

        0/20 
        entrada.addEventListener('input', function () {
  const nome = entrada.value;
  saida.textContent = 'Olá, ' + nome + '!';
  contador.textContent = nome.length + '/20';
  contador.classList.toggle('erro', nome.length > 20);
});

        Ação 7 · Criar e remover itens

        Cada item novo nasce com o seu próprio botão de remover.

          const li = document.createElement('li');
li.textContent = texto;

const x = document.createElement('button');
x.textContent = 'x';
x.addEventListener('click', function () {
  li.remove();
});

li.appendChild(x);
lista.appendChild(li);

          Ação 8 · Vários elementos de uma vez

          querySelectorAll devolve uma lista de elementos, e o forEach passa por cada um.

          MaçãUvaPeraManga
          const nomes = ['Maçã', 'Uva', 'Pera', 'Manga'];
const frutas = document.querySelectorAll('.a8-fruta');

frutas.forEach(function (item, i) {
  item.style.background = '#ffd43b';
  item.textContent = (i + 1) + '. ' + nomes[i];
});
          Final

          Folha de cola da árvore

          Selecionar

          getElementById('id'), querySelector('.classe'), querySelectorAll('li').

          Navegar na árvore

          parentElement, children, firstElementChild, nextElementSibling.

          Escutar eventos

          addEventListener('click' | 'submit' | 'input', função). Outros: mouseover, keydown.

          Ler valores

          .value em campos, .textContent em textos.

          Alterar conteúdo

          textContent para texto puro e innerHTML para HTML.

          Alterar aparência

          style.cor para ajustes rápidos e classList.toggle para trocar o visual por classe.

          Alterar atributos

          setAttribute, disabled, hidden, type.

          Criar e inserir

          createElement e appendChild.

          Remover

          elemento.remove() ou innerHTML = '' para esvaziar.
